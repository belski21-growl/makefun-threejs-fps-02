NORTHLIGHT — Aurora Relay: a round-based tactical FPS in three.js. 5v5 Raiders vs Wardens on a snowy alpine relay station at night (48×40 m, aurora, frozen pool). The Raiders carry a pulse charge to one of two sites (Beacon or Depot, drawn per round); first to 4 rounds (max 7). Buy economy between rounds ($800 start, kill +$300, win +$3,250), 5 weapons + frost frag, bot squads with push/hold/engage/plant/defuse/retake behaviour, fixed-step 60 Hz seeded simulation, synth WebAudio sound, full HUD + buy menu + spectate.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.ts
```
